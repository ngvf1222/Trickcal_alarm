# 리뉴아

리뉴아 봇은 트릭컬 이벤트, 쿠폰 알림과 연회장 검색을 지원하는

교주가 만든, 교주들을 위한 트릭컬 봇입니다.

### [초대링크](https://discord.com/oauth2/authorize?client_id=1267694210262372362&permissions=8&integration_type=0&scope=bot)

## 기능들

1. 트릭컬 이벤트 발생시 사전 설정한 채널로 알림
2. 새로운 쿠폰 발생시 사전 설정한 채널로 쿠폰코드 알림
3. 사도별 연회장 선호 음식 정보 제공
